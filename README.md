# Pepco POS

Przeglądarkowy system punktu sprzedaży (POS) i kasy fiskalnej zbudowany w HTML5, CSS3 i JavaScript z myślą o sprawnym przebiegu obsługi sprzedaży i rozliczeń.

## Główne funkcje
- **Obsługa sprzedaży i rabatów** — naliczanie rabatów na pojedyncze pozycje oraz na cały paragon, a także wyliczanie reszty w podglądzie dokumentu.
- **Dokumenty sprzedaży i zwrotów** — numeracja dokumentów sprzedażowych i zwrotowych, w tym paragonów, faktur (z NIP i bez NIP), faktur korygujących oraz zwrotów.
- **Kartoteka kontrahentów i towarów** — zarządzanie kontrahentami z obsługą NIP oraz przyjmowanie towarów seryjnych z filtrowaniem kategorii i osobnymi polami kodów PLU oraz EAN.
- **Dedykowana klawiatura ekranowa** — wbudowana klawiatura ekranowa w motywie Pepco, blokująca systemową klawiaturę Androida na ekranach dotykowych.

## Uruchomienie
Otwórz aplikację w przeglądarce internetowej (najlepiej w trybie pełnoekranowym / kiosku na docelowym urządzeniu).
